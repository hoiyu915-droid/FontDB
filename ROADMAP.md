# Roadmap

FontDB is maintained incrementally. Priorities are ordered by evidence and downstream need rather than fixed dates.

## Near term

- Complete license, source, and CJK coverage verification for remaining semantic profiles.
- Expand deterministic glyph, weight, and fallback stress tests.
- Publish reproducible installation and integration examples.
- Define release tags and compatibility notes for downstream consumers.

## Later

- Add community-submitted integration fixtures and usage records.
- Stabilize the schema and deprecation policy for a 1.0 release.
- Improve automated provenance checks without weakening human review.

Roadmap items are proposals, not promises. Material changes should begin with an issue and follow `CONTRIBUTING.md`.
