# Contributing to FontDB

Contributions are welcome through GitHub issues and pull requests.

## Before opening a pull request

1. Open or reference an issue for material behavioral, schema, or policy changes.
2. Keep each pull request focused on one concern.
3. Preserve canonical data sources and fail-closed validation rules.
4. Add or update tests and documentation when behavior changes.
5. Run the repository's documented validation commands.
6. Do not commit secrets, private datasets, copyrighted source material, or assets without redistribution rights.

## Review

Maintainers review correctness, provenance, licensing, backward compatibility, and reproducibility. Passing automated checks is necessary but does not by itself authorize a merge.

AI-assisted contributions are accepted. Contributors remain responsible for reviewing generated changes, verifying sources and licenses, and describing material AI assistance in the pull request.

By contributing code, you agree that it is licensed under Apache-2.0. By contributing data, documentation, or original visual assets in the paths identified by `NOTICE.md`, you agree that those contributions are licensed under CC BY 4.0 unless a file states otherwise.
